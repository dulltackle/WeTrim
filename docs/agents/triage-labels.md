# Triage 标签

各个 skill 都以五个规范的 triage 角色来表述。本文件把这些角色映射到本仓库 issue 追踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签      | 含义                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 需要维护者评估该 issue     |
| `needs-info`               | `needs-info`      | 等待报告者补充更多信息     |
| `ready-for-agent`          | `ready-for-agent` | 描述完备，可交给 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要人来实现               |
| `wontfix`                  | `wontfix`         | 不予处理                   |

当某个 skill 提到一个角色时（例如「打上 AFK-ready 的 triage 标签」），使用上表中对应的标签字符串。

如果你实际使用的是另一套标签词表，改右边这一列即可。
