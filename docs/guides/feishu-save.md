# 将文章保存到飞书

WeTrim 把当前保留内容保存为多维表格记录，图片保存为附件。清洗、Markdown 导出与飞书连接相互独立；没有飞书权限仍可清洗和导出。

## 复制与连接

1. 在「飞书连接」打开[十二列文章收藏模板](https://dulltackle.feishu.cn/base/SKQdbFpCOaipFws5nercV1wwnMe?table=tblrP4IsRN8d2ctW)。选择「创建副本 / Make a Copy」→「仅复制结构」，保存到自己的空间。不要向公共母模板写入。
2. 检查自己副本的分享范围，按需要限制访问。副本应有十二列：「标题」「公众号名称」「原文链接」「原文发布日期」「保存时间」「正文」「标签」「图片」「文章关联标识」「分篇序号」「分篇总数」「保存状态」。保存状态必须为单选，包含「未完成」「已完成」。额外列可以保留。
3. 从副本的数据表复制标准链接，形如 `https://你的空间.feishu.cn/base/…?table=…`。不能使用不含数据表信息的链接或知识库 wiki 链接；不要手工猜内部编号。
4. 在副本 Base 的扩展工具中取得个人授权码。填入 WeTrim 的目标链接和授权码；不要把码发到聊天、截图、Issue 或日志。它只保存在当前浏览器本地，不同步到其他浏览器。
5. 点击「检查连接」，在 Chrome 原生提示中允许访问飞书官方接口。浏览器访问权限与飞书授权码是两层独立权限。检查只读取目标和字段，不写文章或测试记录；核对显示的目标后点击「确认连接此表格」。

首次检查按标准名称和类型识别，确认后保存副本自己的字段 ID。改列名仍可按 ID 识别；删除、错误类型或缺状态选项会暂停。先修复结构再检查；删除后重建列需要恢复标准名称，点击「按标准列名重新检查映射」并重新确认。WeTrim 不会替你建表、改列或公开副本。

## 先用独立测试保存

连接区的「写入示例正文和测试图片」会写入固定示例和一张测试图片，不使用你的文章。只有正文、附件、图片字节和首篇完成状态全部核对后才显示通过，并提供目标表链接。打开记录检查可读正文和可打开的图片。

测试会留下真实远端记录及上传素材。失败也可能留下部分结果，不会自动回滚。确认无需保留后，在飞书表格中找到本次示例记录，通过行菜单删除；不要删除别人的记录。仅上传而未关联的素材可能没有可见记录，按飞书提供的素材管理能力处理，不要把删除行当作已证实清除所有素材。

## 保存文章与分篇

编辑、取舍后点击「保存到飞书」。只保存当前保留块的 Markdown，不包含剔除块、空白块、转换提示或导出的 front matter。来源缺失时留空。标签可选已有项，也可输入新项；去掉空白和完全重复项，取消不会写入新标签。

同目标已有相同原文链接时会提示，确认「另存」会创建新组，保留旧记录与人工修改。长文按正文预算分篇，每篇最多 100 个附件；尽量保留段落、列表和代码完整。单张图片超过 20 MiB、下载失败或单个不可拆图片语法超预算会在写入前阻止。跨篇正文依篇序拼接，所有篇共享来源、时间、标签和文章关联标识。

**只有首篇的「已完成」代表整份保存完整。** 其他篇保持「未完成」，不表示那些篇失败；先按文章关联标识找全组，再按分篇序号阅读。首篇只有在全部正文、图片和关联核对完成后才更新。保存期间继续编辑清洗内容不会改变已固定的保存计划。

## 失败、恢复与另存

浏览器关闭后，用同一浏览器配置重新打开 WeTrim，选择「核对并继续原次保存」。恢复基于当时固定内容，不要求清洗会话仍在。已上传图片优先核对回执；未上传图片需重新获取来源，图片二进制不保存在恢复数据里。

- 明确失败：修复权限、连接或字段后重试，仅补未完成部分。
- 结果待确认：远端可能已成功。保持原计划，稍后核对；查不到一次不代表失败，不要连续另存期待去重。
- 图片上传成功但回执缺失：若无法核对，不会盲目再次上传，可能需要保留暂停或放弃。
- 远端记录被人工修改或删除：暂停，不覆盖旧结果。可恢复远端一致内容后核对，或明确「另存原次完整内容」到新组；新组仍使用固定内容并重新预检全部图片。
- 图片来源失效或副本字节变化：保持未完成；可修复来源再试，或放弃。无法保证图片源、回执永久有效。

「放弃这次保存」只清除本机恢复内容，保留清洗、连接以及远端已写部分。之后不会自动找回被放弃的本机进度；请自行查看和管理远端部分。

## 换码、换表、清除与撤销

同目标更新授权码后重新检查并确认，可保留原进度并先核对旧结果。鉴权失败不能当作记录不存在。未完成时换表，选择取消以继续原次保存，或明确放弃旧恢复后连接新目标；新目标使用新组和新回执。

「清除本机连接」需要确认，会删除当前浏览器的授权码、目标配置和恢复内容，保留清洗会话和远端数据。已经发出的远端写入可能仍成功，清除不会回滚它；迟到返回不能继续后续保存或重新建立旧连接。

本机清除不等于撤销飞书授权。要让旧码失效，请到目标 Base 获取授权码的工具中关闭或重置授权码。要撤销浏览器访问，请在 Chrome 扩展详情中调整 WeTrim 的飞书站点访问权限；再次连接时从产品按钮申请。两种撤销分别影响浏览器访问和飞书鉴权，不会删除你的文章。
