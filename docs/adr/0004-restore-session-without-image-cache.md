# 恢复清洗进度时重新获取图片

清洗会话持久化文章来源、块的原始 HTML、初始内容、当前编辑与取舍，以及图片地址和必要来源信息；不额外保存整篇原始 HTML，也不持久化图片文件。恢复直接使用保存的块记录，图片按保存的地址重新获取，以控制单篇持久化的数据范围，避免引入离线图片缓存的管理成本。

这一选择保证清洗内容与取舍可恢复，但不保证图片离线可见：断网或源图片失效时显示占位及重试入口，仍允许继续编辑文字；导出继续遵循已有的图片失败和明确保留外链规则。后续不能把图片缓存误当成已有的恢复承诺。

决策来源：[决策：持久化模型与会话生命周期](https://github.com/dulltackle/WeTrim/issues/7#issuecomment-5582245317)。开发者已确认完整契约；保存失败、版本兼容和会话替换等边界以该票的解决评论为准。
