# 列表与引用整体成块，普通段落中的图片独立成块

WeTrim 的内容块是用户独立取舍正文内容的单位，其边界同时影响清洗交互与保存的编辑状态。列表和引用各自整体成块，内部文字通过编辑 Markdown 删改，以保住编号、缩进和引用结构；普通段落中的文字和图片则按原顺序拆块，使图片可以独立剔除。

这一选择放弃了列表项和引用内段落各自独立的取舍开关。它是清洗粒度的产品决策，并不表示复杂嵌套结构的解析已经获得样本验证。

列表、引用、表格等完整内容单元内部不再递归生成可独立取舍的块；其中的图片通过编辑所属块的 Markdown 取舍。所有块均可编辑和还原内容，编辑后的内容即使改变形态，也沿用原块身份和初始类型，不自动重新切块。

决策来源：[建模：「块」的精确定义](https://github.com/dulltackle/WeTrim/issues/5)，开发者已在本次讨论中确认上述边界。
