# 任一时刻最多一个编辑中的内容块

清洗会话在任一时刻最多只有一个编辑中的内容块。进入另一个内容块的编辑时，立即提交上一个块尚未保存的当前内容，结束其编辑并清除未完成的还原确认；被动退出不移动焦点，焦点归新进入编辑的块。主动点击「完成编辑」仍将焦点收回本块容器。

这一约束由块列表统一管理，双击正文、编辑按钮（含键盘操作）和图片引用定位共用它。各块保留本地输入与既有自动保存节奏，进入编辑前先让旧块提交，避免切换入口绕过未完成的编辑。编辑状态属于当前界面，不写入持久化清洗会话。

相较于各块独立维护开关、允许多个编辑器同时展开，单一编辑块让逐块清洗时的当前编辑对象明确，也避免切换后残留还原确认。代价是不能并排改写多个块；切换必须提交旧块，且要区分主动与被动退出的焦点行为。双击只增加入口，不按初始块类型限制编辑，也不映射正文双击位置到 Markdown 源码位置。

决策来源：[实现：双击正文进入 Markdown 编辑（#39）](https://github.com/dulltackle/WeTrim/issues/39)。
