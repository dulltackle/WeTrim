# 从保存的文章快照恢复块身份

每次抓取为文章快照及其内容块生成独立身份，保存块的原始内容、初始转换内容、当前编辑和取舍状态；恢复时直接使用保存的记录，不重新抓取、切块或匹配 DOM。重新抓取同一文章得到新的快照，不自动迁移旧编辑，以避免文章变化或切块规则变化时把修改贴到错误内容上。

这一选择需要保存足够的原始记录，并放弃重新抓取后的自动编辑迁移；保存时机、替换提示、图片缓存与存储配额由[决策：持久化模型与会话生命周期](https://github.com/dulltackle/WeTrim/issues/7)继续确定。

决策来源：[建模：「块」的精确定义](https://github.com/dulltackle/WeTrim/issues/5)，开发者已确认恢复原记录、重新抓取不自动迁移编辑。
