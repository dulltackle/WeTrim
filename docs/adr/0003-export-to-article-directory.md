# 将文章直接导出到独立目录

WeTrim 的目标用户无需理解压缩包，导出后即可使用 Markdown 和图片；v1 因此从独立扩展全页调用目录选择器，每次由用户选择父目录，再创建独立文章目录。同名时新建带后缀的目录，保留已有结果，不承诺原地更新笔记库中的文章。

这一选择将目录授权与多文件写入的失败处理纳入导出流程，并放弃 v1 的 ZIP 交付和跨会话默认目录设置。目录写入和单文件保存均已有原型验证，选择目录是用户体验取舍，而非 ZIP 无法实现；具体命名、内容格式、图片和失败规则以[决策：导出产物的精确形态](https://github.com/dulltackle/WeTrim/issues/6#issuecomment-5581985012)的解决评论为准。
